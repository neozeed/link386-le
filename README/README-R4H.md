# R4H Sarien linker comparison

This is an experimental forensic checkpoint, NOT a repaired executable. Extract the archive, run `make verify-r4h-fixups`, then read `build/r4h-differential.txt`, `build/r4h-fixup-diff.txt`, and `HANDOFF-R4H.md`. The full R4G source, 42 original OMF Sarien modules, LIBC.LIB, OS2386.LIB, and Microsoft reference are included. The reference is used for verification only. The previous live-proven CMD32 and hello linker source profiles were not altered.
